把 Planet 612 装到手机

装上后有独立图标、全屏运行、断网也能用

iiPhone / iPad（Safari）

  1. 用 Safari 打开这个网址（必须是 Safari，微信/Chrome 里不行）
  2. 点底部中间的「分享」按钮（方框加向上箭头）
  3. 下滑找到「添加到主屏幕」
  4. 右上角点「添加」
装好后从桌面图标打开，没有地址栏、没有浏览器按钮，跟真 App 一样。长按桌面图标还能只跳某一个工具（体重 / 收支 / 时光 / 透视）。

A安卓（Chrome / Edge）

  1. 用 Chrome 打开这个网址
  2. 点右上角「⋮」菜单
  3. 选「安装应用」或「添加到主屏幕」
  4. 确认「安装」
如果菜单里找不到「安装应用」，说明这个浏览器暂不支持 PWA 安装，换 Chrome 或 Edge 即可。

装上之后有什么不同

📱
独立图标 + 全屏桌面有图标，点开没有地址栏
📴
断网也能用地铁、电梯、没信号的地方照常记录
⚡
秒开直接读本地缓存，不用等网络
🔒
数据还是你自己的记录存在手机本地，同步仍走你自己的 GitHub
🔄
联网自动更新有新版本会静默拉取，不用重装
关于数据安全，说一句实话 「安装」只是给网页加了个外壳，你的记录仍然存在手机浏览器的本地存储里，不是存在 App 里。所以：换手机、清理浏览器数据、卸载浏览器，都可能丢数据。重要数据请照常用「同步到 GitHub」备份一份。
