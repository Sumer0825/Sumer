这一类靠看金额榜永远发现不了——每次花得更少，但次数翻倍。节流手段是砍次数，不是砍单价。

高消费 「家庭采购 / 个人置物 / 冲动消费 / 其他」

账单只能给线索，「这笔钱该怎么归」最终由你判断。家庭采购=家里要用的（柴米油盐日用品，刚需）·个人置物=给自己买的（衣服数码，能省但要权衡）·冲动消费=买完就后悔的（最该省）·其他=暂时不属于上面三类（房租、还款、学费等刚性支出）。分类结果会累积保存，下次打开直接读。
🔒 标记保护
设置密码后，取消分类或更改分类需要输入密码，防止误点把已经想清楚的判断改掉。首次分类不受影响。
💡 密码只在本机以加盐哈希形式保存（不明文存储），换设备需各自设置。忘记密码可用应急密码 870825 解除。
☁️ GitHub 同步配置
「家庭采购 / 个人置物 / 冲动消费 / 其他」的分类结果默认只存在这台设备的浏览器里，换一台设备就看不到。填一次 GitHub Token 后，标记会写入仓库里的独立文件 data/analysis-marks.json，所有设备共享。Token 只存本机浏览器，不上传到任何服务器。
💡 同一份标记在多设备间按内容指纹（日期+类型+金额+分类+子类+备注）匹配，所以哪怕两台设备各自导入过账单、记录编号不同也能对上。只写标记文件，不会碰你的 data/ledger.json 账单文件。
