把记账 App 导出的 Excel 拖进来，自动整理成图表——收入支出趋势、分类占比、每月盈亏、累计结余一目了然。

GitHub 同步设置

把数据写入你仓库里的 data/ledger.json（含全部账单记录），多设备自动共享（每次导入 = 一次 commit）。Token 仅存于本机浏览器，不会上传到任何服务器。

💡 每个浏览器 / iOS 主屏幕图标都有独立存储：换环境需重新配置一次 Token；保存后数据自动从 GitHub 云端拉回，不会丢。
本工具使用独立的配置文件（ledger_gh_cfg_v1），与其它工具互不干扰。
